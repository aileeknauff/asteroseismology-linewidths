# Data Directory

Place your asteroseismology data files in this directory.

Supported formats:
- CSV files with frequency, power columns
- FITS files from Kepler/TESS missions
- Text files with whitespace-separated values

Example data structure:
```
# frequency (microHz), power (ppm^2/microHz)
1000.0, 0.0234
1000.5, 0.0256
...
```
